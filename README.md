# Synaos Staff Frontend Engineer Technical Challenge

Spec-driven design notes and supporting code for an industrial-automation frontend scenario (`SPEC.md`).

This repo is an [Angular](https://angular.dev/) 21 application (standalone components, routing, SCSS). Run it locally:

```bash
npm install
npm start
```

Then open http://localhost:4200/. Use `npm run build` for a production bundle. Use `npm test` for Vitest-powered unit tests (`npm run test:ci` runs once with no watcher).
